# Battle Arena

Gerador de batalhas visuais personalizáveis para vídeos, Reels e TikTok.

## Primeira versão
- Participantes ilimitados (mínimo 2)
- Nome, emoji ou upload de logo/imagem
- Arena circular responsiva
- Física de movimento e colisão
- Lâmina/ataque giratório
- Vida e dano configuráveis
- Eliminação automática e campeão
- Velocidade e tamanho configuráveis

## Rodar
```bash
npm install
npm run dev
```

Abra o endereço mostrado pelo Vite no navegador.
